Publicar Grátis no GitHub Pages (Custo R$ 0,00)

Este aplicativo foi arquitetado em arquivo único (index.html) sem dependências de build, pronto para hospedagem gratuita vitalícia com HTTPS automático:

  1. Crie um repositório público no GitHub (ex: clipchatt-studio).
  2. Envie este arquivo salvo exatamente como index.html para a raiz do repositório.
  3. Vá em Settings → Pages, selecione a branch main e pasta / (root) e clique em Save.
Dica: Você também pode conectar o repo na Vercel ou Cloudflare Pages.
